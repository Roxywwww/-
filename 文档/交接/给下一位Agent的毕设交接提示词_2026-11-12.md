## 4. 硬件与接线，特别注意已经踩过的坑

系统是20 kg额定量程应变式称重梁、双亚克力秤盘、HX711模块、STM32F103C8T6核心板、四针OLED、三脚DS18B20和两个功能按钮。老师允许核心板插接自制载板。设计采用分体式，秤架与控制PCB分开，PCB用支撑柱固定，多数连接使用插座。OLED及按钮按最终实物方式安装。

| --- | --- |
| HX711 PD_SCK | PB12 |
| HX711 DOUT/DT | PB13 |
| OLED SCL、SDA | PB8、PB9，软件I²C |
| OLED供电 | 3.3 V与GND |
| 去皮键 | PA5到GND，上拉输入，低电平按下 |
| g/kg切换键 | PA3到GND，上拉输入，早期PA4已改为PA3 |
| DS18B20 DQ | PA12，约4.7 kΩ上拉至3.3 V |
| DS18B20供电 | VDD接3.3 V、GND接地，DQ同时连接GPIO和上拉电阻下端 |

| USART1输入 | PA10，纯接收采集一般用不到 |

DQ经电阻接3.3 V，避免直接把DQ短接到3.3 V。PA12已用于温度总线，若以后启用USB功能要检查引脚冲突。三线接口编号是载板自定义编号，连接探头前仍按DS18B20实物朝向核对GND、DQ、VDD。

## 5. 当前代码到底做了什么

接手后请核对源文件，以下是交接时核对结果。

- HX711读取24位补码，有符号扩展，补第25个脉冲选择下一次A通道128倍增益。等就绪有200 ms超时，短暂移位传输期间保护时钟时序。
- 开机自动去皮，PA5按下也去皮。每次取16个样本均值，有读数失败或端点饱和值时整次去皮失败。这里并非剔除坏点后继续凑满16个。成功后更新offset并清空滤波窗口，失败时保留原基准。
- 正常主循环称重路径并没有与去皮过程同等的饱和拦截。若后续完善固件，需要检查±端点以及tare无效时的显示、滤波和输出处理。实际24位端点是−8388608与+8388607。
- `net = raw - tare_offset`，net的单位仍是ADC计数。
- 暂定斜率为177.6184计数/g，代码常量 `HX711_COUNTS_PER_GRAM_X10000 = 1776184LL`。克数为net除以177.6184，别误写成1776.184。计算用64位整数中间量，按0.1 g单位取整。
- `main.c` 中 `HX711_AverageAdd()` 使用5点等权滑动平均，每次加入最新净计数、移出最旧净计数。计算式为 `net_avg = (最近 N 个 net 的和) / N`，刚开始 `N` 取实际已有样本数，最多5个。`HX711_NetToTenthsOfGram()` 将单次和平均净计数分别换算成 `g` 与 `g_avg`，OLED显示滤波后的结果。16次均值只用于建立去皮基准。当前主控的称重滤波是这一个滑动平均窗口，IIR和软件工频陷波均待评估。
- 称重报告间隔参数为200 ms，OLED刷新间隔为500 ms。报告节奏与HX711内部转换速率分别核对。
- PA5与PA3采用30 ms消抖及按下/释放状态逻辑。g显示一位小数，kg显示四位小数。显示切换不会把历史串口g字段自动变成kg。
- DS18B20使用微秒时序、单总线命令及CRC，转换等待参数为800 ms、失败重试参数为1000 ms。等待过程用状态机推进。固件仍是主循环结构。
- 温度输出形如 `temp_c=26.68`，异常输出 `temp_error=no_presence` 或 `temp_error=read_or_crc`。温度目前参与显示与记录，质量计算使用固定系数。
- OLED软件I²C在PB8/PB9，历史显示与拔线后TEMP ERROR经用户确认过。
- 温度补偿、现场标定参数保存、断电保留校准参数均待设计实施。温度功能的单独使能开关也须查代码，不能假定已经实现。

## 9. 第一轮冰杯空载预实验，我该怎么操作

目的为得到温度—时间、raw—时间和raw—温度关系，检查装置能产生的温区、热滞后、结露与连续记录质量。

1. 用保温袋或双层保温袋围出空间，底部采用稳定硬支撑。秤架放其中，控制PCB、电脑与转串口放外部，穿线孔留松量。保温袋保持固定，避免随开合改变支撑力。
2. 冰杯采用带盖密封容器或封好的冷源，另有稳定放置面和防漏措施，放在秤架旁。冰杯不作为秤盘负载，不接触秤梁和秤盘，探头贴梁侧测温。
3. 供电后先连续观察约20～30分钟，结合温度与空载趋势决定预热是否足够。实际等待时间写入事件表。
4. 先启动采集。若要记录完整开机信息，确认空载后复位一次并记录。需要手动去皮时在开始基线前做一次。随后保留约10分钟室温空载基线，整个温度过程保持同一去皮基准。
5. 标记加入冷源，放入冰杯并关袋，标记关袋。此后保持秤盘空载，不触摸梁和盘，不移动接线，不重复去皮或复位。
6. 连续观察冷却和自然回温，先计划2小时，必要时延长。冰融化后水仍可能很冷，不能以冰全部化完作为梁温恢复的判据。若回温迟迟不发生，可移走密封冷源并记录开盖、取杯、关袋的时刻，避免碰秤。
7. 出现持续无温度、无称重、供电/接触异常或结露时，记录时刻并处理，不把故障区间当作温漂。处理造成移动或重启时标记新的阶段，必要时重新开会话。
8. 在实际温度趋向室温且读数趋势可判断后，保留末段基线。Ctrl+C停止，确认JSON有结束原因，CSV/TXT/BIN均保存。记录起止、实际温区、杯子动作、结露和其他异常，拍照归档。

正式记录温点用实测梁侧温度。冰杯主要覆盖低于室温及回温区间，不能保证达到10 ℃，也不能产生高于室温的30 ℃、40 ℃温点。若任务最终保留四个温点，需要借助受控环境或另设计可测量的温源条件；条件达不到时向老师说明实际温区并调整实验表述。

这一轮之后先做数据质量报告和曲线，再决定稳定温区和加载时机。若第一轮温度变化小、异常多或称重趋势明显受开袋影响，先调整装置后重复预实验。

## 10. 后续如何放砝码，如何得到可验证的补偿

### A. 时间漂移对照

尽量增加同装配、同供电、相近持续时间的室温空载记录，帮助判断通电预热和时间漂移。固定载荷长时输出还可能包含机械蠕变。OIML把蠕变定义为恒载及环境不变时输出随时间的变化，因此单次升温曲线中的漂移应结合对照解释。[OIML R60-1](https://www.oiml.org/en/files/pdf_r/r060-1-e21.pdf)

### B. 多温区空载和带载测量

优先在多个相对稳定的梁温附近完成相同的加载序列。温度稳定的起始观察条件可设为连续5分钟温度极差不超过0.1 ℃，再检查更长时间的趋势。该数值是初步实验判据，应根据预实验调整并记录，不能只凭一个探头的短窗波动证明整机热平衡。

## 11. 数据分析与模型，怎样才能回填论文

先生成数据质量摘要，再拟合。保留所有原始行，派生数据标明剔除原因。每个稳定段需要run_id、segment_id、状态、起止时间、参考质量及依据、有效样本数、raw均值/标准差、温度均值/极差、升降温方向、距加载时长、温度年龄和有效性、供电及装配版本。

raw使用ADC计数；温度使用℃；质量统一用g。对无温度、过期温度、饱和、tare无效、掉线、意外移动、加载过渡和结露区间做可追溯标记。旧CSV列名与新格式不同，分析脚本应能识别或提供明确转换。模拟数据必须另存，图表标题或文件名注明模拟。

先看三类曲线，温度随时间、空载raw随时间、raw对温度散点并区分升降温。温度与时间在单轮实验中可能相关，只有一条连续回温曲线时先报告观察关系，结合重复、室温对照和残差判断模型能否推广。

任务书用 `W(T) = W0 + α·(T−T0) + S(T)·W` 表达零点项和灵敏度项，要求拟合温度系数。论文初稿把同一思路写成ADC计数域模型，实验和固件统一使用下面的符号与单位。

```text
ΔT = T − T0
R = b0 + α·ΔT + k0·m + γ·m·ΔT + ε
m_hat = (R − b0 − α·ΔT) / (k0 + γ·ΔT)
```

其中R为原始计数，m为参考质量，T为梁侧温度，T0为固定参考温度。b0是参考温度空载计数，α为零点温度系数，k0为参考温度计数/g，γ为斜率随温度的变化。各单位依次为计数、计数/℃、计数/g、计数/(g·℃)。如用β=γ/k0，单位为1/℃。参数命名保持与论文一致。

在这套符号下，空载曲线是 `R0(T) = b0 + α·ΔT`，称重灵敏度是 `k(T) = k0 + γ·ΔT = k0·(1 + β·ΔT)`。空载预实验可以估计零点随温度变化的斜率α。带载试验在不同温度下用已知质量估计 `k(T)`，才能识别γ。若论文报告去皮后的空载质量漂移，用 `e0(T) = (R0(T) − R0(T0))/k0` 将空载变化换算成g。在此线性模型中，未补偿的理论斜率为 `α/k0`，单位g/℃。正式结论用独立验证数据计算补偿前、后的残余斜率，保留初始去皮时间和参考温度。

最小二乘拟合可使用稳定段均值构成设计矩阵 `[1, ΔT, m, m·ΔT]`。拟合前检查温度和载荷覆盖及矩阵秩，不能把全部低温都设为空载、全部高温都设为500 g后拟合四个参数。只取得空载数据时先估计b0与α，k0、γ需要相应载荷信息。每温区先拟合斜率与截距再观察它们对温度的变化，也可作为交叉核对。

模型优先从固定系数、零点修正和零点加灵敏度修正依次比较。选择复杂度时看独立数据的残差与误差，实际没有改善也要保留结果和解释。参数表保存T0、适用温区、载荷区间、单位、训练会话号、版本和拟合方法。

同一批独立验证样本分别计算上述三种方法的结果，比较各载荷、温区、轮次的偏差、MAE、RMSE、最大绝对误差及空载等效质量温漂斜率。标准差与绝对误差分别报告。R²作为辅助拟合指标，不能独自证明补偿有效。大量同一稳定段的行不等于大量独立重复试验。

最终应有温度—时间曲线、空载与带载漂移图、零点/灵敏度对温度关系、补偿前后验证误差图、误差分布图，以及系数表、条件表、分组误差表。图中标清实测或离线重算，轴单位、采集会话、样本和筛选区间可追溯。
