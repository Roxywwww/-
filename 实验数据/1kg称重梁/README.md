## 文件位置

- `原始数据/串口采集`：每次采集独立建立日期时间会话目录，保存原始字节、串口文本、记录表、事件和会话说明。
- `分析结果`：标定参数、统计窗口、图表及补偿验证结果，并链接对应原始会话。
- 阶段结论继续记在`实验数据/阶段记录`，并更新[实验要求与验收目标](../实验要求与验收目标.md)。总索引新增条目时保留实际路径；旧会话不移动、不改写为新梁结果。

## 开始采集前

旧20 kg软件已经分别保存[已确认运行版与长按取零待实测版](../../固件归档/20kg_2026-11-25/README.md)。后续解压到独立1 kg工程副本，不覆盖20 kg归档和旧工程；具体编译、烧录及新标定系数记录在新梁会话中。

安装新梁后重新确定每克计数，不沿用20 kg梁的178.20计数/g。会话记录梁的额定量程及编号、装配/探头位置、实际运行的固件版本、标定系数、供电和参考砝码。先核对秤盘、支架及载荷的总承重。

11月26日已新增`工具/串口采集/开始采集_1kg.cmd`及`采集_1kg.py`，仓库内运行固定保存到本目录下的`原始数据/串口采集`；笔记本便携包则保存到脚本旁`采集数据/1kg`，与20 kg分开。启动时和固定面板会显示版本及保存位置。分量程入口不接受`--output`覆盖；底层`collect_serial.py`仍保留维护用的显式输出参数。版本由操作者选择，不是自动识别金属梁，详见[保存说明](../../工具/串口采集/先看这里_保存位置.md)。

新旧梁比较采用相同载荷、预热/取零安排、采样和滤波设置、统计窗口；分别使用各自标定系数换算成克。比较空载波动、加载重复性及卸载回零，不直接比较原始计数跳动幅度。

本轮两段已结束采集：`2026-11-26_12-31-44_518120`为旧系数下原始计数标定，`2026-11-26_12-50-44_025410`为新系数烧录后核对。20/50/100 g独立增量约19.965/50.056/99.930 g；板上100 g示值约100.091 g，卸载后约0.167 g，仍有约0.129 g回零变化。当前仅室温单轮结果，温度补偿与长时稳定性尚未验证。当前工程未带入PA5长按待实测功能。

## 尚待导师讨论的方向

操作者考虑与导师讨论增加蓝牙手机采集，或调整题目及温度补偿研究要求。目前没有获批调整，不修改原任务书、已提交报告或当前验收目标。蓝牙可改善数据传输与查看，不能替代零点和温漂问题的验证。
