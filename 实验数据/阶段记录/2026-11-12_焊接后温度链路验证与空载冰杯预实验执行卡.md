# 焊接后温度链路验证与空载冰杯预实验执行卡

日期：2026-11-12。本文是现场操作卡，不是实验结果。上午记录时PCB尚未接入温度传感器；下午重新连接后，COM11的60秒检查已经获得有效重量和温度，10分钟桌面空载数据也已保存，但空载raw存在初期漂移。连接已确认可用，正式冰杯实验仍须先完成更长预热和后段稳定性判断，详见[桌面空载连接检查与稳定性测试记录](2026-11-12_桌面空载连接检查与稳定性测试记录.md)。

## A. 焊接前：断电和朝向

1. 拔掉USB、ST-Link和所有外部供电，确认板子不带电。
2. 按DS18B20实物封装和原厂数据手册核对GND、DQ、VDD，不能只按导线颜色判断。常见TO-92平面朝己时引脚为1 GND、2 DQ、3 VDD，但必须以实际器件标记和数据手册为准。
3. 目标引脚关系：DQ接PA12，约4.7 kΩ上拉至3.3 V；VDD接3.3 V，GND接GND。不得把DQ直接短接到3.3 V。
4. 避开应变片封胶、开槽和活动变形区，传感器贴梁侧；引脚与焊点绝缘，线束在固定端留松量并固定。只能对传感器引脚短时焊接，避免塑料封装和应变片受热损伤。
5. 先拍照记录传感器朝向、焊点、贴附位置和线束走向。

## B. 上电前：万用表断电检查

记录仪表型号、档位和实测值，不把换算值写成重新测得的值。

1. 3.3 V与GND之间检查供电短路；DQ与GND、VDD与GND不得呈低阻短路。
2. DQ到3.3 V之间应有约4.7 kΩ上拉，保留实测读数及所用电阻档。
3. 检查PA12焊点、探头三线、接插件和转接线端到端导通，移动线束时不能时通时断。
4. 检查HX711朝向仍为`IC FACE DOWN`，4针/6针插装关系与实物丝印一致；检查HX711实际供电和GND。
5. 发现冒烟、异常发热、供电短路、气味或焊盘脱落时立即断电，不继续采集。

## C. 上电后：先验证，不先做冰杯

1. 空载放置秤盘，记录实际5 V、3.3 V端电压及测量档位。不得沿用历史4.89 V、3.28 V作为今天读数。
2. 连接PA9 TX到USB转串口RX，并共地；GPIO逻辑3.3 V。采集不需要连接PA10或转串口TX，已供电板不再从转串口VCC供电。
3. 先关闭串口助手释放端口，然后运行：

```powershell
python .\工具\串口采集\collect_serial.py --list
```

4. 只看端口列表选择新出现的实际电子秤端口，不猜COM号。运行1分钟连接检查：

```powershell
python .\工具\串口采集\collect_serial.py `
  --port COM实际编号 --seconds 60 `
  --label "焊接后连接检查" `
  --experiment-type "温度链路验证" `
  --assembly-version "实际板版号" `
  --firmware-version "实际固件版本" `
  --module-id "实际HX711编号" `
  --sensor-id "实际DS18B20编号" `
  --probe-position "梁侧实际贴附位置" `
  --power-supply "实测5V/3.3V及档位" `
  --reference-mass "空载" `
  --thermal-source "无" `
  --note "焊接后首次检查；本会话只验证连接，不作为温漂实验"
```

5. 合格条件：出现连续`temp_c=...`，温度年龄不超过约5秒，没有持续`temp_error`；`raw`不持续饱和/超时；OLED与串口显示一致；去皮偏移有效。温度暂时错误时先查焊接/上拉/引脚，不靠重复复位掩盖。
6. 与可信参考温度计放在同一稳定环境比对，记录温度计型号、分辨率、读数时间和位置。DS18B20在−10～85℃典型准确度±0.5℃，显示两位小数不等于0.01℃准确度。
7. 单独做一次断线/恢复试验：记录拔线时刻，确认出现错误且旧温度未冒充新温度；重新接回后出现新`temp_c`。异常注入数据不得混入正式温漂统计。
8. 按PA5检查空载去皮，按PA3检查g/kg单次切换，并确认OLED、串口和按键状态一致。下载固件会重启并自动去皮，不能在有载荷或正式采集时执行。

## D. 空载冰杯预实验：准备

只有C阶段全部合格后才开始。

1. 保温袋底部用稳定硬支撑，秤架置于袋内；控制PCB、电脑和转串口置于袋外，穿线孔留松量，袋壁和线束不能施力于秤盘。
2. 冰杯带盖密封或使用密封冷源，放在秤架旁，不放在秤盘上，不接触秤梁。另行防漏；控制板保持干燥。
3. 传感器贴梁侧测梁温，不放入冰杯。贴附位置、胶层、线束和冷源距离拍照。
4. 供电后连续观察约20～30分钟，记录温度与空载raw趋势；实际是否预热足够由趋势判断，不把固定等待时间写成热平衡证明。
5. 关闭休眠，接通电脑电源。确认盘上确实空载后再复位/去皮；进入温度过程后保持同一去皮基准，不重复复位或去皮。

## E. 两小时过程与事件输入

1. 启动采集时填写真实端口和全部场次信息，设置`--hours 2`或持续运行。开始时在窗口输入`c base 室温空载基线开始`。
2. 保留约10分钟室温空载基线，不碰秤梁、秤盘、探头和接线。
3. 放入密封冰杯后立即输入`c cold 加入冰杯`，关好保温袋再输入`c close 关袋完成`。事件时刻是电脑输入时刻，真实动作可能有秒级延迟。
4. 全程空载。观察温度—时间、raw—时间；温度错误、持续超时、供电/接触异常或结露时输入`c fault 说明`并处理，故障段不当作有效温漂。
5. 计划观察2小时。若长时间不恢复，可移走冷源：输入`c remove 取走冷源`，避免碰秤。不要用“冰已全部融化”单独判断梁温恢复。
6. 当温度已朝室温回升并保留末段基线后，按`Ctrl+C`正常停止。确认目录内`summary.json/.md`存在，`session.json`的`status`和`stop_reason`正常，原始CSV/TXT/BIN完整。

## F. 结束后先做质量检查

本轮先检查，不急着宣称温漂结论：

- 是否全程有有效温度，温度错误多少行、多少段；
- 有效温度和实际温区是什么，降温与回温是否完整；
- 是否有数据中断、复位、去皮、意外碰触或结露；
- HX711是否饱和/超时，时间漂移是否明显；
- 冷源加入、关袋、移走和稳定段的事件时刻；
- 是否需要在改善保温、固定或探头贴附后重复预实验。

只有质量合格后才进入室温对照和多温区带载。单条冰杯回温曲线只能先报告观察关系；零点与灵敏度模型、独立验证和论文结果必须在真实数据到齐后再写。
