# 称重传感器历史线色核对与记录更正

日期：2026-11-01。用户为重新制作PCB核对此前用电桥电阻法排查的称重传感器四芯线。

依据[2026-10-13接线排查记录](2026-10-13_20kg传感器与HX711接线排查记录.md)“接线调整与复测”段，20 kg称重传感器历史修正接法为：

| 传感器本体线色 | HX711功能端 |
| --- | --- |
| 红 | E+ |
| 黑 | E− |
| 白 | A− |
| 绿 | A+ |

商家初始接法将白接E+、红接A−，对应此前raw=-8388608及A+/A−对E−约1.36/2.73 V的异常状态，不应误当成修正结果。

当时六组电阻中，黑—红392 Ω、白—绿343 Ω形成互不共线的较大电阻配对；结合电桥节点电位分析，推定红黑为激励对、白绿为信号对，按上述目标接法调整后用户发送了随加载变化、卸载恢复的原始读数。电阻配对本身不能单独确定正负极性，也不是所有传感器通用的颜色规则。

发现10月22日《原理图第二轮核对》曾将初始商家线色误记为已排查结果，已原位标注日期并纠正，保留原错误内容的说明，避免继续引用。没有改写原始电阻、电压或串口数据。

当前尚未对用户重新接线后的实物做通断复测。表格是历史记录回查，不是本日新测量结论；新PCB的连接器1～4脚顺序必须依据当前实物接头与模块实际插装方向独立核对，不能从线色表推断照片的左右或焊盘序号。HX711数字侧VCC/GND接反冒烟与传感器E/A线色属于不同接口问题。
