# STM32 电子秤接口底板：原理图与 PCB 规划

日期：2026-10-20  
状态：设计草案，尚未画入嘉立创 EDA、尚未打板；本文件不代表电路或尺寸已经实测通过。

## 定位与已验证功能

采用现有 STM32F103C8T6 Type-C 开发板、HX711 小板、20 kg 四线称重梁、四针 OLED、PA5 去皮按键、DS18B20 三线温度探头。底板主要负责**模块插装、连接、电源分配和机械安装**，不重复绘制开发板上的 MCU 最小系统，也不把 HX711 芯片直接焊在底板上。当前固件引脚：PB12=HX711 SCK，PB13=HX711 DOUT，PB8=OLED SCL，PB9=OLED SDA，PA5=去皮，PA12=DS18B20 DQ，PA9/PA10=USART1 TX/RX。温度 DQ 最终是否仍用 PA12，见下文待定项。

## 原理图建议分为六块

| 模块 | 原理图内容 | 连接 |
|---|---|---|
| 1. 开发板插座与供电 | 将整块开发板画成一个模块符号，板上对应两排 1×20 排母；标出 5V、3V3、GND、用到的 GPIO、NRST、SWD。优先从开发板 Type-C 单路供 5V；底板提供 5V/3V3/GND 测试点。 | 不能把另一独立 5V 源直接并到 Type-C VBUS。 |
| 2. HX711 与称重梁 | HX711 小板两侧插座：传感器侧 E+、E-、A+、A-、B-、B+，数字侧 GND、DT、SCK、VCC；四线称重梁另设有方向标记的四针接口，接 E+、E-、A+、A-，B 通道不用。 | DT→PB13，SCK→PB12；HX711 VCC 与逻辑电平方案未定稿。 |
| 3. OLED 显示 | 四针插座，按**实物丝印顺序**定义 GND、3V3、SCL、SDA。 | SCL→PB8，SDA→PB9；OLED 板上是否已装 I²C 上拉需检查，额外上拉可留不焊位。 |
| 4. 去皮按键 | PA5 到按键、按键另一端接 GND；现有程序使用内部上拉。按键可装在 PCB 边缘或经两针接口接外壳按键。 | 不与 NRST 混用。可预留独立复位测试点/按键位。 |
| 5. DS18B20 外置探头 | 三针接口：3V3、DQ、GND；4.7 kΩ 从 DQ 上拉到 3V3。温度传感器本体装在称重梁附近，三根绝缘线接插头。 | 当前程序 DQ→PA12；建议先核实/改用空闲 PB14 再定稿。 |
| 6. 调试接口 | 三针串口接口：PA9 TX、PA10 RX、GND，供 3.3 V 电平 USB 转串口使用；保留开发板 SWD 插头及 Type-C 接口可触达的空间。 | 调试器/USB 转串口的供电脚不作为另一电源输入。 |

所有接口丝印同时标明功能、极性和 1 脚，不能只写 J1/J2。原理图尽量用 5V、3V3、GND、HX_DT、HX_SCK、LOAD_A_P、LOAD_A_N、TEMP_DQ 等网络标签，减少跨图长线；称重梁接线以已经查验的**实物**颜色对应关系为准，不依赖常见颜色惯例。

## 打板前必须消除的两处电气不确定性

1. **PA12 与 USB D+ 共线。** 资料中的旧版核心板原理图把 PA12 接到 USB D+，还画有通过 4.7 kΩ 接 5V 的支路；用户手中的开发板为 Type-C 版本，不能假设这张旧图完全对应实物。建议将 DS18B20 DQ 改到当前空闲且引出的 PB14，避免与 USB 数据线共用；这需要同步改 `.ioc` 和固件并在面包板上复测。若坚持 PA12，至少先确认实物电路与上电空闲电压，不能仅以目前“温度能读到”为充分依据。
2. **HX711 模块的 5V/3.3V 数字接口。** 当前称重验证阶段曾给 HX711 小板 5V，MCU 为 3.3V。HX711 芯片资料建议数字电源 DVDD 与 MCU 电源相同，但小板是否把 VCC 直接接到 DVDD，要以该块实物电路为准。底板定稿前确认其 VCC→DVDD 关系、DOUT 高电平和 SCK 输入兼容性；选定 3.3V 供电并重新验证，或保留 5V 并做明确的电平匹配。不能将目前可读 raw 当作最终接口裕量验证。供电方式改变后需重新标定。

## 封装和机械尺寸

- 旧版核心板尺寸图给出约 **53.34 mm × 22.86 mm**、两排中心距 **15.24 mm（600 mil）**、同排 **2.54 mm** 节距及每排 20 孔；用户的 Type-C 实物要核对板长、两排中心距、针脚方向和 USB 插头伸出空间，再建立底板封装。可用两条 1×20 排母作为实际焊件，开发板垂直插入。
- 现有 `HX711_MODULE_10P_P2.54_20.32.kicad_mod` 是按照片估算的早期封装，文件本身注明**排距未经卡尺验证**，不可直接据此打板。应测 HX711 实物两排/两侧孔中心距、各排首孔位置和板外形，再在嘉立创 EDA 专业版重建 6+4 插座封装。
- OLED 四针的针距、排针方向以及从板边/外壳可见的位置须按实际模块测量。最终秤盘、称重梁安装螺钉和底座外形先固定，再决定 PCB 外形、安装孔与连接器朝向。

## PCB 布局顺序

1. 先画机械边界、安装孔、称重梁及秤盘运动禁布区；PCB 和线束不能碰秤梁或分担重量。确定 Type-C、OLED、按键和线束的出入口。
2. 放开发板两条排母，使 Type-C 能从外壳插入，复位/BOOT/SWD 可操作；检查开发板与底板上其他器件的高度和底面焊点净空。
3. 把称重梁四针接口与 HX711 小板放在同一区域，靠近传感器引线入口。A+、A- 走线短且相邻，远离 USB 5V、OLED 时钟、HX711 SCK；不要把传感器差分线绕过开发板。
4. 把 OLED 接口放前沿、按键放人手可触及处、温度三针接口放探头电缆出口，留理线和抗拉位置。温度探头应固定在靠近称重梁、每次一致的位置，避免只测到 PCB 自身温度。
5. 两层板可用连续 GND 铺铜，先布电源与称重模拟线，再布数字线；在 5V、3V3、GND、HX_DT、HX_SCK 等处留测试点。检查外壳螺钉、电源插头、插拔动作不会压到小板。

## 嘉立创 EDA 专业版的实际绘制顺序

先建立开发板模块符号与封装、HX711 模块符号与封装，再放常规插座、电阻和按键；连接网络并逐个核对符号引脚号与封装焊盘号；运行原理图 DRC；随后使用“设计 → 更新/转换原理图到 PCB”，先完成机械布局，再走线、铺铜和 PCB DRC。最后按 1:1 打印封装与板框，拿实物开发板、HX711、OLED 和外壳比对孔位与插拔空间。流程参见[嘉立创 EDA 专业版快速入门](https://prodocs.lceda.cn/cn/quick-start.html)。

## 2026-10-20 补充：底座、外置 OLED 与 Type-C 供电顺序

用户计划 OLED 也通过四根线连接底板，机械结构尚未定型。建议先用纸板、亚克力或已有底板做**尺寸样机**：固定称重梁和秤盘，标出底板的最大长宽、高度、安装孔、Type-C 开口、OLED 显示窗、按键位置及各线束出口；无需在此时把外壳做成最终成品。根据样机尺寸画 PCB，打板试装后再完成正式底座。PCB 不应碰到活动秤梁，线束也不能分担或牵拉称重载荷。

OLED 用四针接插件引出 `GND/3V3/SCL/SDA`，顺序以实物丝印为准。杜邦线适合面包板验证；成品用有定位和防松能力的四芯插头更可靠。OLED 排线不与称重梁的 A+/A- 信号线长距离并行捆扎。

供电暂按“**一根 Type-C 线给核心板输入 5V**”设计。旧版核心板图显示 USB VBUS 与板上 `5V` 网络相连，因此其 5V 排针可作为底板的 5V 分配点；但现用 Type-C 实物与旧图版本不同，下单前必须在只接 Type-C、其他电源断开时用万用表测 `5V-GND` 与 `3V3-GND`，再接入模块复测电压。5V 排针只是把外部 USB 5V 引出来，开发板不自行生成 5V；可供电流取决于 USB 电源、开发板走线与接插件。建议底板 5V 预留给 HX711（其电平匹配问题须另行解决），OLED 与 DS18B20 接 3.3V。ST-Link 或 USB 转串口调试时共地，避免额外并接供电脚形成双路供电。

## 2026-10-20 补充：分体结构与实测供电

用户报告开发板供电端测得 `5V-GND = 4.89 V`、`3V3-GND = 3.28 V`；测量时负载、电源设备和仪表误差未记录。这两个数值接近标称电压，仅用于当前供电检查，不能单凭它们确认最大供电能力、HX711 数字电平兼容性或称量精度。后续应在最终接线与工作负载下复测并记录条件。

用户提供的现状照片显示双亚克力秤盘/称重梁和面包板电路已经分开摆放，称重梁自带四芯引出线。结构方案暂定为**分体式**：保留秤盘与梁的机械总成；单独制作一个装有接口 PCB 的控制盒，STM32 开发板和 HX711 小板插装在 PCB 上，OLED 与按键可用短线固定到控制盒面板。称重梁的四芯线接入 PCB 上带明确极性丝印的四针端子；DS18B20 使用三芯线固定在秤梁附近，接入 PCB 上三针端子。控制盒尺寸由实物模块、Type-C 插拔空间和线束弯曲空间确定，可在 PCB 布局确定后制作，不必先定制精细外壳。秤盘机械件需保持固定端与受力端独立，线束固定防拉扯，避免线束传力。

称重梁到 HX711 的四芯是 `E+、E-、A+、A-`：前两根为电桥激励电源，后两根为微弱差分输出，并非四根都属于差分数据线。分体式可以按现有四芯线长度布置，尽量不额外延长模拟线；若后续控制盒离秤盘较远，应评估噪声、线阻和校准变化，优先缩短模拟段，必要时把 HX711 移近秤梁再把数字信号接回控制板。最终线长、接头与供电方式确定后重新标定并测重复性。

按用户提供的任务书截图，要求有 STM32/HX711 接口电路、硬件电路及 PCB 制作、显示和温度补偿实验；**未规定 PCB 必须在秤盘下方、OLED 必须直接焊在 PCB 上，也未要求一体式外壳**。指导教师已同意 STM32 开发板插接到 PCB，因此此分体接口底板方案符合当前已知的结构约束。此处是方案选择，尚未打板或验证成品性能。

盒顶两个瞬时按钮可用各自两芯线连接 PCB 的两针插座，而非受限于 PCB 位置：去皮键接 `PA5/GND`，复位键接开发板 `NRST/GND`，接口名称和线序分别标清。去皮键沿用程序的输入上拉；复位键只是硬件复位，不当作取消去皮。按钮端可焊线并绝缘，PCB 端优先插接以便拆盒。若用户说的两个按钮中包含电源开关，则电源件应改用保持型开关并串在选定的供电路径上，不能按普通 GPIO 瞬时按钮接法绘制。

若两个按钮都位于盒顶，复位键宜选凹入式或与去皮键明显区分，防止带载误触后自动去皮；更易用的成品布局是盒顶去皮键与预留模式键，复位留在盒侧小孔或开发板原键处。当前尚未给模式键分配 GPIO，也未实现模式按键代码。

## 2026-10-20 补充：外露式单 PCB 备选结构与模块孔位验证

用户提出省去控制盒，将 OLED 和两个按键直接安装在同一块接口 PCB 上，称重梁通过四芯线连接。此方案可以作为正式样机：PCB 是独立控制面板，必须用安装孔和支撑柱固定到非受力底板/小亚克力片上，尤其在按键附近留支撑；板和线束不得碰到活动秤盘或秤梁。OLED 可用合适方向的四针插接结构及安装柱固定到板面，不能仅靠四根裸线悬吊。Type-C 开口、开发板和 HX711 的堆叠高度、OLED 可视面和按键手指空间需在 PCB 布局时同时检查。没有盒子仍需要基本绝缘、固定与线束防拉扯。

关于 1:1 纸样：先在 EDA 中按暂定尺寸放置 1×6 和 1×4 两个排母孔阵列，打印 PCB 封装/局部板图时选 `100%` 或 `实际大小`，关闭“适合页面/缩放”；同时画一条 `20 mm` 校验线，打印后用尺量这条线是否为 20 mm。拿已经焊排针的 HX711 实物，让十个针尖同时对准纸上的十个孔中心；如果两排不能同时对齐，就回 EDA 调整两排距离和相对位置，再打印复核。这个纸样是制板前的低成本机械核对，不等于实际 PCB 试插，也不能验证孔径或插座高度。用户目前用普通尺难以直接量准两排距离，因此该方法优先于凭照片猜孔距；有条件仍用卡尺和实物排母复核。

用户给出的 B 站专栏/视频与百度网盘分享链接在当前网页访问工具中无法直接打开；已核对本地同名 HX711 资料包，未发现可直接用于此 6+4 小板的机械尺寸图。网络上不同卖家的 XFW-HX711 外形尺寸不一致，不能代替用户实物测量。当前供电开关路径、OLED 具体安装方向和两个顶部按钮的功能分配仍为布局待定项，未改固件。

## 2026-10-20 结构决策：分体式外露接口 PCB

用户确定采用**分体式**：称重秤盘与控制 PCB 分开；控制 PCB 不装盒，PCB 下方四处支撑/安装位以防按键操作时弯曲；尽量使用接插件便于调试、拆装。STM32F103C8T6 开发板现有两排公针，接口 PCB 需对应两排母座；HX711 小板现有 6P+4P 公针，接口 PCB 对应两个母座。称重梁四芯线接四针端子；DS18B20 保持在称重梁附近并引线到板上；OLED 和操作件优先考虑直接安装在接口 PCB 上。此前“控制盒内 PCB、盒顶 OLED 与按键”的布局设想由本决策取代。

画图和打板时，四个支撑点应避开称重梁受力路径和 PCB 走线，按键附近要有足够支撑；母座尺寸与两排中心距必须和实物核对，尤其是 HX711 的 6+4 错位与开发板 Type-C 空间。用户希望亲自操作嘉立创 EDA 以学习原理图/PCB 流程，协作方式为逐块绘制、逐项复核引脚和网络、ERC/DRC 与 1:1 实物试装。当前只是设计决策，尚未形成可制板文件或通过电气/机械校验。

## 2026-10-21 原理图草稿第一轮截图核对

用户在嘉立创 EDA 中已摆放：称重梁四针接口、HX711 模块 6P/4P、STM32 开发板两排 20P、OLED 四针、一个按键和 4.7 kΩ 电阻，并按功能分区。此时截图中的 HX711/称重梁接口、按键和电阻还有悬空引脚，不能据此认为网络已接完或可以转 PCB；截图也不足以确认符号与封装的焊盘编号映射。

建议外置 DS18B20 三芯线在原理图用 `J_TEMP` 三针接口表示，PCB 对应三个有镀铜通孔的焊线盘（也可暂用 1×3、2.54 mm 通孔焊盘封装并注明“不装排针，直接焊线”），编号和丝印明确 `GND/DQ/3V3`。4.7 kΩ 的 R1 接在 DQ 与 3V3 之间；温度探头本体应固定在秤梁附近，焊线孔旁预留应力释放位置。当前 `.ioc` 与 `main.h` 明确 DQ=PA12；若最终选择 PB14，需先同步修改固件和接线并重新验证，不能只改原理图。

第一轮重点复核：HX711 实物 6P 和 4P 的逐针顺序，以及称重梁四针端子正面/背面的编号；OLED 当前 H4 若 1=GND、2=3V3、3=PB8/SCL、4=PB9/SDA，则与已验证接法一致，但仍要按实物模块丝印确认；KEY1 应接 PA5/GND，若另外增加复位键则接 NRST/GND。PA12 在 STM32F103 上兼作 USB D+，开发板 Type-C 实际布线尚未核对，最终 PCB 优先考虑迁移到空闲 PB14 并复测。HX711 的 5V/3.3V 数字接口仍是供电定稿项。功能分区标题/框线只是图形，不形成电气连接；必须用导线或网络标签，并运行 ERC 和核对网表。

用户拟采用单控制盒：PCB 位于盒中；盒侧为称重梁四芯线、温度传感器三芯线及供电线的出入口；OLED 经四芯线接 PCB 并固定在盒顶。称重线长度与出线方向关系到盒子能放在哪里，也关系到模拟信号抗扰和最终标定，不能完全忽略；优先利用现有线长，尽量不增加接头或随意加长。四芯进线经盒壁固定/护线，再接 PCB 的 `E+ E- A+ A-` 端子；HX711 模块插在该端子旁。OLED 排线用有定位的四芯接插件替代最终成品中的松动杜邦头。

操作件建议分为：① 保持型电源开关；② 瞬时去皮按键，继续使用 PA5；③ 瞬时复位按键，可并到开发板 NRST 与 GND，是否引到盒面视现有板上复位键的可触达性决定。校准仍可通过串口完成，PCB 可预留独立模式/校准按键焊盘供后续扩展。若继续从开发板自身 Type-C 直接供电，焊在接口底板 5V 支路上的开关无法关闭开发板本体；盒面电源开关需采用 USB 输入前的开关方式，或改为底板独立 USB 供电入口、开关后再向开发板 5V 脚供电。这两种供电架构尚未定稿，不能同时把两路 5V 直接并用。

当前 `hx711test/Core/Src/main.c` 上电后会自动执行 HX711_Tare；因此复位按键并非“取消去皮”，带载按复位会把当时载荷当作新的零点。复位键建议做成不易误触的维护键；正常使用只操作去皮键。若需要任务书提及的 g/kg 切换，预留一个模式按键比把复位键兼作模式键更清楚。

DS18B20 若用于秤梁温度补偿，应将传感器本体固定在秤梁附近，而非直接焊在控制盒内 PCB 上；其三根引线可以焊到 PCB 的 `3V3/DQ/GND` 焊盘，但需留应力释放和绝缘，也可用三针插座方便拆装。DQ 到 3.3V 的约 4.7 kΩ 上拉放在 PCB 上。当前 PA12 引脚仍有 USB D+ 共线疑点，定稿前应决定是否迁移并验证。

## 2026-10-21 温度焊线口的确定方案与 EDA 操作状态

用户明确选择外置 DS18B20：探头本体固定在秤梁附近，三芯线直接焊到接口 PCB，不装 TO-92 于接口 PCB，也不装三针排针。原理图应放一个 `J_TEMP` 三针器件符号，PCB 关联恰好三个有镀铜通孔的焊盘。约定编号如下，符号引脚号和封装焊盘号必须逐一相同；板上在焊盘旁清楚标 `GND / DQ / 3V3`。

| 引脚/焊盘号 | 网络 | 当前接点 |
| --- | --- | --- |
| 1 | GND | 核心板 GND，DS18B20 GND |
| 2 | DQ | 核心板 PA12，R1 4.7 kΩ 一端 |
| 3 | 3V3 | 核心板 3.3 V，R1 另一端，DS18B20 VDD |

建议封装为 `1×3` 通孔焊线盘，中心距可取 2.54 mm，但实际孔径应按三芯线线径及焊接工艺确认；焊盘之间留绝缘余量，在线束入口做机械应力释放。原理图备注为“直焊三芯线，不安装排针”，若库器件原型是排针，还需在 BOM 中标为不装，避免物料表误采购。
