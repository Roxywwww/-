# 电子秤毕设实验要求与验收目标

更新于 2026-11-21。依据任务书截图、10 月 16 日导师答复、11 月 13 日收到的温漂实验答复截图，以及本项目的原始数据和阶段记录。接手实验、修改固件或撰写实验章节时先查本页，新增实测后更新对应证据。

## 任务书原定要求

| 项目 | 原定要求 | 当前证据与缺口 |

| 量程及性能 | 0～350 g、0.1 g 分辨率、非线性误差在 ±0.5% 内 | 已实现 0.1 g 显示步进；有效分辨率、全区间非线性、重复性待验证。若按 350 g 满量程计，0.5% 对应 1.75 g，该百分比的参照量仍待确认。 |
| 软件 | 去皮、实时显示、g/kg 切换，滤波原文为“IIR 50/60 Hz + 滑动平均” | 已实现开机及 PA5 去皮、5 点滑动平均、PA3 单位切换代码和 OLED 显示。并行一阶 IIR 低通已完成离线对照、烧录和板上短时空载验证。HX711 自带工频抑制与 STM32 软件滤波分别交代，约 5 Hz 的读数无法直接实现 50/60 Hz 陷波。见[滤波对照](阶段记录/2026-11-16_IIR滤波离线对照与采集接口.md)。 |

## 导师回复与待确认口径

- 导师对温漂问题回复“去皮后的”。实验采用开始时在空载条件下去皮一次，记录参考温度和偏移，跨温点保留这一基准。空载用来估计零点漂移，同温度下的带载与空载差用来估计灵敏度变化。每温点重新去皮会消除零点漂移信息。
- 导师对传感器与量程问题回复“按照你的实际情况调整，这个没关系的。”可按当前 20 kg 额定称重梁开展实验，报告标明实际验证的载荷范围。
- 最新截图中，导师回复温点无需严格卡在 10、20、30、40 ℃，按大致区间测量。低温可利用自然气温下降，高温可用保温袋或吹风机模拟。导师希望根据实测解释结果、体现温度补偿有一定效果，并通过设计实验和讨论体现工作量。
- 最新回复未明确补偿后 ≤0.05 的单位或是否作为硬性验收线，也未指定只看空载还是带载。任务书原文保留；论文若采用 g/℃，写明是去皮后称重示值对实测梁温的变化率，列出载荷与验证条件。
- 11月21日再次核对原11月13日聊天截图：导师仍希望温度补偿“有一定效果”，同时建议增加实验设计和分析讨论；未明确免除补偿验证。当前问题是温度关系与跨轮改善的可重复性，不能把空载需要始终显示0作为建模前提，也不能在未定位前将全部漂移归因HX711。

## 已完成的实验与证据

- 11月21日取消OLED的±0.3 g显示归零分支，源代码已改、编译0错误0警告；ST-Link下载连接失败，板上更新未确认。运行中的自动零点跟踪或稳定性门控取零均未实现。此前实验按当时已部署版本与原始串口值解释，不能把代码修改当作新实测性能。见[代码状态与链路检查](阶段记录/2026-11-21_约25度同序载荷对照.md)。

- 11月21日停采后操作者报告直流初测：核心板5 V及HX711模块输入均约4.88 V，桥路激励约4.11 V，3.3 V节点随后确认实测3.30 V，读数未明显变化。该初测未与串口样本同步，也没有纹波测量，不能据此确认或排除供电引起的零漂。见[供电初测记录](阶段记录/2026-11-21_约25度同序载荷对照.md)。

- 11月21日长时段于17:08正常结束，1小时56分54秒，40121行，温度22.12～24.18 ℃，无温度/设备错误及段内串口断档，基准33022计数不变。首尾60秒空载均值−1.384→+0.271 g；约22.32 ℃相近梁温下，不同时间空载仍相差约1.414 g，操作者确认除两次200 g放取外无其他操作。按加载前末段、卸载后首段的近邻空载插值及60秒上限窗口，23.790 ℃和22.429 ℃的200 g加载增量为199.861、199.838 g；30秒窗口为200.073、199.879 g。106个空载整分钟均值的一阶温度拟合R²=0.2456，尚不足以确认稳定的温度补偿关系；本轮没有独立补偿验证，也未更新固件系数。详见[完整结果及曲线](阶段记录/2026-11-21_约25度同序载荷对照.md)与[分析明细](分析结果/2026-11-21_连续降温结果/连续降温分析.json)。

- 11月21日接续长时采集在线核对：同一33022计数零点基准下，24.14 ℃初段空载均值约−1.38 g，22.14 ℃本次加载前空载约+0.19 g，回升约1.57 g；22.35 ℃的200 g带载均值约200.00 g。仅扣加载前空载的暂定增量约199.82 g，仍待卸载后的邻近空载复核。该观察与温度、时间共同变化，不直接当作温度单因果证明或已通过补偿验证。见[11月21日在线核对](阶段记录/2026-11-21_约25度同序载荷对照.md)。

- 11月21日保持去膜后装配和探头位置，完成约24.6～25.0 ℃的200/500/100 g对照。固定178.20计数/g，原段尾窗口口径下前后空载插值的加载增量为199.658、500.065、99.992 g。两日之间重新开机，跨日比较不直接拿去皮后的空载示值相减。随后保持本轮供电和33022计数零点基准，开启独立窗口长时空载降温，现已结束；启动故障造成144.225秒缺测，已保留，不补数据。操作者确认已开门、未去皮复位。最终分析另用近邻空载窗口，具体结果及口径见同日阶段记录。独立补偿验证仍待完成。见[约25度对照及接续采集](阶段记录/2026-11-21_约25度同序载荷对照.md)。

## 后续补测方案与数据保存

1. 按导师最新口径，用自然低温、室温及保温袋缓慢升温安排不同温区，记录实测稳定梁温。优先补低于 20 ℃ 和高于 30 ℃ 的观测，具体温区按条件确定。尽量保持同一装配、供电、探头位置和初始去皮基准，各温区在梁温相近时按同一顺序采空载、标称 200 g、卸载空载。采用吹风机时先间接暖空气，停吹且温度、重量稳定后再取统计窗口。以前的冰杯数据留作预实验，避免直接把跨日空载与带载的差值当成已验证的灵敏度温漂。
2. **借到控温箱时整机进箱，笔记本在箱外**，沿用已焊接的秤体、探头和控制板。若 USB 转串口模块可留在箱外，现有 UART 线（PA9/TX 到转串口 RX，以及共地）穿引线孔，必要时从可插拔的一端穿线后再接回；若转串口模块也固定在整机上，就随整机入箱，从引线孔引出其 USB 数据线。另有独立供电线时也从引线孔穿出。箱外笔记本通过现有 Python 脚本实时保存数据。借用设备时核对引线孔能通过实际插头，线在秤座固定侧留余量。拟合与验证保持相同布置，记录板子和传感器都在箱内，结果对应整机温漂。正式采集前先短采核对重量、温度和供电。
3. 固件通过串口输出重量和温度，电脑持续保存 `records.csv`、`serial.txt`、`received.bin`、事件和会话摘要。实验开始、换载、稳定及异常都记录时刻。按有效温度状态和年龄配对原始计数，保留断档，去皮或复位处分段。发现冷凝时停止该段并记录。
4. 在计数域拟合 `R = b0 + α·(T−T0) + [k0 + γ·(T−T0)]·m`，再按 `m̂ = [R−b0−α·(T−T0)]/[k0+γ·(T−T0)]` 换算。对同一批独立验证数据比较固定标定、零点补偿和零点加灵敏度补偿，报告最大绝对误差、MAE、RMSE 与残余温漂斜率，并注明 R² 对应的拟合对象。整轮留作验证，避免把相邻采样拆成拟合和验证两组。验证支持改进后再考虑启用固件补偿。
