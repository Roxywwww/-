## 导师回复与待确认口径

- 导师对温漂问题回复“去皮后的”。实验采用开始时在空载条件下去皮一次，记录参考温度和偏移，跨温点保留这一基准。空载用来估计零点漂移，同温度下的带载与空载差用来估计灵敏度变化。每温点重新去皮会消除零点漂移信息。
- 导师对传感器与量程问题回复“按照你的实际情况调整，这个没关系的。”可按当前 20 kg 额定称重梁开展实验，报告标明实际验证的载荷范围。
- 最新截图中，导师回复温点无需严格卡在 10、20、30、40 ℃，按大致区间测量。低温可利用自然气温下降，高温可用保温袋或吹风机模拟。导师希望根据实测解释结果、体现温度补偿有一定效果，并通过设计实验和讨论体现工作量。
- 最新回复未明确补偿后 ≤0.05 的单位或是否作为硬性验收线，也未指定只看空载还是带载。任务书原文保留；论文若采用 g/℃，写明是去皮后称重示值对实测梁温的变化率，列出载荷与验证条件。
- 11月21日再次核对原11月13日聊天截图：导师仍希望温度补偿“有一定效果”，同时建议增加实验设计和分析讨论；未明确免除补偿验证。当前问题是温度关系与跨轮改善的可重复性，不能把空载需要始终显示0作为建模前提，也不能在未定位前将全部漂移归因HX711。

## 后续补测方案与数据保存

1. 按导师最新口径，用自然低温、室温及保温袋缓慢升温安排不同温区，记录实测稳定梁温。优先补低于 20 ℃ 和高于 30 ℃ 的观测，具体温区按条件确定。尽量保持同一装配、供电、探头位置和初始去皮基准，各温区在梁温相近时按同一顺序采空载、标称 200 g、卸载空载。采用吹风机时先间接暖空气，停吹且温度、重量稳定后再取统计窗口。以前的冰杯数据留作预实验，避免直接把跨日空载与带载的差值当成已验证的灵敏度温漂。
2. **借到控温箱时整机进箱，笔记本在箱外**，沿用已焊接的秤体、探头和控制板。若 USB 转串口模块可留在箱外，现有 UART 线（PA9/TX 到转串口 RX，以及共地）穿引线孔，必要时从可插拔的一端穿线后再接回；若转串口模块也固定在整机上，就随整机入箱，从引线孔引出其 USB 数据线。另有独立供电线时也从引线孔穿出。箱外笔记本通过现有 Python 脚本实时保存数据。借用设备时核对引线孔能通过实际插头，线在秤座固定侧留余量。拟合与验证保持相同布置，记录板子和传感器都在箱内，结果对应整机温漂。正式采集前先短采核对重量、温度和供电。
3. 固件通过串口输出重量和温度，电脑持续保存 `records.csv`、`serial.txt`、`received.bin`、事件和会话摘要。实验开始、换载、稳定及异常都记录时刻。按有效温度状态和年龄配对原始计数，保留断档，去皮或复位处分段。发现冷凝时停止该段并记录。
4. 在计数域拟合 `R = b0 + α·(T−T0) + [k0 + γ·(T−T0)]·m`，再按 `m̂ = [R−b0−α·(T−T0)]/[k0+γ·(T−T0)]` 换算。对同一批独立验证数据比较固定标定、零点补偿和零点加灵敏度补偿，报告最大绝对误差、MAE、RMSE 与残余温漂斜率，并注明 R² 对应的拟合对象。整轮留作验证，避免把相邻采样拆成拟合和验证两组。验证支持改进后再考虑启用固件补偿。

详细实验安排和论文回填见[论文收尾安排](../文档/交接/论文收尾与温漂验证安排_2026-11-16.md)。完整毕设交接稿保存在本机。
