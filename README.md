# 基于STM32的电子秤设计与温度补偿研究

本科毕业设计工程，使用STM32F103C8T6、HX711、DS18B20和OLED。此仓库保存固件、开题材料、阶段记录及原始数据；温度补偿模型与最终整机指标仍需通过后续实验确定。

## 固件与接线

| 功能 | 引脚 |
| --- | --- |
| HX711 DOUT / PD_SCK | PB13 / PB12 |
| OLED SCL / SDA | PB8 / PB9 |
| 去皮按键 | PA5，对地按下，使用上拉输入 |
| g/kg单位切换按键 | PA3，对地按下，使用上拉输入 |
| DS18B20 DQ | PA12，外接约4.7 kΩ上拉至3.3 V |
| USART1 TX / RX | PA9 / PA10，115200、8N1 |

现有固件包含原始计数读取、开机及按键去皮、质量换算、5点滑动平均、OLED显示、单位切换、DS18B20时序与CRC校验。PA3程序已构建下载，实物按键验证状态以阶段记录为准。温度目前用于显示和记录，尚未参与质量补偿。

开机时保持秤盘空载，固件会自动取零点。比例系数是临时装配下的初步标定结果，最终供电与机械结构固定后应重新标定。0.1 g显示位数不等于已验证的0.1 g测量准确度；也不能根据当前小载荷数据宣称20 kg全量程精度。

## 在另一台电脑继续开发

```powershell
git clone https://github.com/Roxywwww/-.git stm32-scale
cd stm32-scale/hx711test
code .
```

已有本仓库的电脑先运行`git pull`。在VS Code中打开`hx711test`文件夹，使用“Keil: 编译”任务，或直接在Keil中打开`MDK-ARM/hx711test.uvprojx`。下载任务为“Keil: 编译并下载”，需要ST-Link和已安装的相关驱动。

本机任务脚本使用`C:\Keil_v5\UV4\UV4.exe`。另一台电脑应安装相应Keil环境、ARM Compiler 5与STM32F1器件支持包；若安装位置不同，调整`hx711test/.vscode/keil.ps1`中的Keil路径。器件支持包及编译产物不随仓库上传。
